Why a second model, and why Claude has the last word为什么要换一个模型审查，又为什么由 Claude 最终确认

A model reviewing its own work tends to agree with itself. A different model catches different mistakes, but it also makes claims it cannot back up. So reviews are evidence, not verdicts.模型审查自己的产出，往往会认同自己。换一个模型能发现不同的错误，但它也会提出站不住的意见。所以审查结果只是证据，不是结论。

Everything goes through files一切通过文件交接

Executors and reviewers never see the conversation. Each slice gets a self-contained handoff; state lives on disk, so a crashed session can resume.执行者和审查者看不到对话。每个切片有一份自足的交接文件；状态写在磁盘上，会话崩溃后可以接着跑。

Executors work in a fence执行者在围栏里工作

Only the files listed under "May modify". No git commands, no weakened tests. A task that needs more reports BLOCKED instead of improvising.只能改"可修改"清单里的文件，不许动 git，不许削弱测试。需要越界时报告 BLOCKED，而不是自作主张。

Reviews are structured审查结果是结构化的

Every finding needs a severity and quoted evidence. Codex output is schema-checked; Claude reviewers validate their JSON with the same script.每条意见都要有严重级别和原文证据。Codex 的输出用 schema 校验，Claude 审查者用同一个脚本自检。

Confirmation is never delegated确认环节从不外包

Claude reruns the verification commands, reproduces each finding, marks it VALID or INVALID, and adds anything the reviewer missed. Only then does it commit the files in scope.Claude 自己重跑验证命令，逐条复现意见，标记成立或不成立，并补上审查者漏掉的问题，然后才提交范围内的文件。

Too lenient: tests CI would never run太宽松：CI 根本不会运行的测试

The reviewer called pytest-style tests a style nit. CI runs unittest without pytest, so 14 new tests would silently never run. Confirmation caught it.审查者把 pytest 写法的测试当成风格问题。CI 用的是不装 pytest 的 unittest，14 个新测试会悄悄不运行。确认环节抓到了它。

A miss on a delete command删除命令里的漏网之鱼

A job in cancel_failed may still have a live worker, yet prune treated it as finished. Neither reviewer raised it; the orchestrator did.cancel_failed 状态的 job 可能还有活着的进程，prune 却把它当成已结束。两位审查者都没提，编排者提了。

Too strict: three findings downgraded太严格：三条意见被降级

Round 2 raised symlink races rated blocker. Checked against the threat model, a private 0700 job root, they became minor follow-ups, with reasons on file.第 2 轮提出的软链接竞态被标成 blocker。对照威胁模型（0700 的私有目录）核实后降为 minor，理由都记录在案。
